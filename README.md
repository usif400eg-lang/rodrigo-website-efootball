# RODRIGO Files — Download Hub ⚡

A modern, high-performance download portal and admin management system for RODRIGO eFootball optimization & configuration files, organized by RAM range and FPS.

## ✨ Features

- **Gaming Aesthetic**: Glassmorphism design, neon accents (cyan/purple/blue), smooth animations, and responsive layout.
- **Categorization & Filtering**:
  - Filter by RAM size: `2-3 GB`, `4-6 GB`, `6-8 GB`, `8-12 GB`, `12-24 GB`
  - Filter by Target FPS: `30 FPS`, `60 FPS`, `90 FPS`, `120 FPS`, `240 FPS`
  - Instant live search by name, RAM, or FPS.
- **Full Admin Control Panel (`admin.html`)**:
  - Protected by admin password.
  - Add, edit, or delete configuration files.
  - Upload custom product/file images with automatic client-side compression and drag & drop.
  - Live statistics for files, downloads, and RAM categories.
  - Real-time `localStorage` synchronization across open tabs.

## 🚀 Technologies

- HTML5 (Semantic & Accessible)
- Vanilla CSS3 (Custom properties, Glassmorphism, Neon glow)
- Modern JavaScript (ES6+, LocalStorage API, Canvas image compression)
